## Как пользоваться

### Статусы задач

| Метка | Значение |
|---|---|
| 🔵 Не начата | Задача не взята в работу |
| 🟡 В работе | Кто-то пишет код / обсуждает с владельцем данных |
| 🟢 Готово в коде | Локально работает, но не подтверждено в эксплуатации |
| ✅ В проде | Проверено с реальными сервисами |
| 🔴 Блокер | Ждём внешнего решения (доступ, владелец данных) |
| ⚪ Не подтверждено | По коду нельзя доказать эксплуатационную готовность |

### Приоритет (MoSCoW)

- **Must** — без этого продукта нет.
- **Should** — сильно улучшает опыт, но можно отложить.
- **Could** — приятно, но не критично.
