# План редизайна partner_edit.html

Статус: **черновик, ожидает запуска**. Бэклог Kate от 2026-10-17. Вернёмся к этому документу, когда Kate даст отмашку.

## Контекст

После волны токенов (CSS) и JS-полировки Kate открыла `partner_edit.html` и `settings.html` и увидела, что вёрстка «кривая, положение кнопок отвратительное». Зафиксировано 12 конкретных проблем по 3 скриншотам.

## Принципы

1. **Не переписываем страницу целиком.** 354 строки, 6 форм, риск сломать. Работаем точечно.
2. **Повторяющееся — в макросы.** Если паттерн встречается 2+ раза, выносим в `_macros.html` или `_application_rows.html`.
3. **Новые визуальные состояния — отдельными CSS-классами**, не inline-стилями. Классы: `.segmented`, `.danger-zone`, `.app-row`, `.icon-button`, `.form-footer`.
4. **Все отступы — через токены** `--space-N`, заведённые в прошлой волне. Никаких новых «магических» px.
5. **Опасные действия визуально отделены** от обычных (другой цвет, другой регион, другой border).
6. **Backend не трогаем** — все правки только в `templates/`, `static/`, `i18n.py` для новых подписей.

## Что делаем по каждой из 12 проблем

| # | Проблема | Решение |
|---|---|---|
| 1 | «Открыть» (ссылка-призрак) | Рендерим только если URL непустой: `{% if value %}<a>Открыть</a>{% endif %}` |
| 2 | Email/Telegram как 2 прямоугольника | Переделать в `.segmented`-контрол: одна обёртка с тонкой рамкой, 2 равные кнопки, активная — белый фон + тень внутри |
| 3 | «Unlink Telegram» как обычная кнопка | Заменить на красную текстовую ссылку под полем @username, мелким шрифтом, с `data-confirm` |
| 4 | 4 кнопки в шапке вразнобой | Разделить на «Действия» (карточка сверху, primary = «Запросить через Telegram») и «Навигация» (текстовая ссылка «← Все партнёры» отдельно) |
| 5 | «Архивировать» рядом с «Сохранить» | Sticky footer c «Сохранить / Отмена», а «Архивировать» — в `.danger-zone` карточке внизу страницы, с заголовком «Опасные действия» |
| 6 | «Приложения для расчёта» дублируется | Добавить внутренний заголовок секции в карточке таба, чтобы было ясно — это часть таба, а не отдельная страница |
| 7 | 5× «Посмотреть письмо» подряд | Заменить на `.icon-button` «↗ Письмо» (компактнее, в одну колонку справа) |
| 8 | «Открыть общие даты · Открыть в Настройках» неразличимы | Одна — primary, другая — text-link (разная интенсивность) |
| 9 | Чекбокс «Свои даты» еле виден | Увеличить до 18×18, добавить рамку, ясный hover/focus |
| 10 | Кнопка × удаления приложения | Увеличить до 32×32, красная иконка при hover, tooltip «Удалить приложение» |
| 11 | «Категория не указана» как placeholder | Плейсхолдер серым (`color: var(--muted)`), выбранная категория — нормальным |
| 12 | Неравномерные отступы в `partner_edit.html` | Пройтись и заменить все `margin/padding` на `var(--space-N)` |
