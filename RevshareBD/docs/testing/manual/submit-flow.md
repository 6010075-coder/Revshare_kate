# Ручной сценарий: веб-форма партнёра (submit-flow)

Пошаговая инструкция «как руками проверить всё, что партнёр делает через веб, без Telegram». Один прогон занимает ~10 минут. Покрывает: P-01 (через веб), P-02, P-03, P-09, P-10, P-11, P-12, P-13, P-14, P-15.

## Предусловия

- `revshare-web` запущен на `127.0.0.1:43127`.
- В БД есть те же партнёры, что и для bot-flow: один с одним приложением, один с несколькими, один без приложений.
- У каждого есть токен персональной ссылки (видно в `/admin/partners/{id}/edit`).
- Браузер (Chrome / Safari / Firefox — что используется в команде).

## Что подготовить

Те же файлы, что для bot-flow (хватит 2–3):
- Заполненный шаблон с 2–3 клиентами.
- Шаблон с одним клиентом.
- Шаблон с «битым» `B3`.

## Ход сценария

### Шаг 1. Открыть персональную ссылку

1. В браузере: `http://127.0.0.1:43127/submit/<TOKEN_ПАРТНЁРА_С_ОДНИМ_ПРИЛОЖЕНИЕМ>`.
2. Должна открыться страница с формой загрузки: поле «Месяц», поле «Файл».

**Ожидаемо:** страница загружается без 5xx, видны подсказки по формату файла.

---

### Шаг 2. Скачать шаблон

1. На странице должна быть ссылка «Скачать шаблон» (XLSX и/или CSV).
2. Скачайте, откройте в Excel/LibreOffice.

**Ожидаемо:** файл пригоден для заполнения.

**Истории:** P-01 (через веб).

---

### Шаг 3. Загрузить «хороший» отчёт

1. Выберите месяц в поле (или оставьте определение по файлу).
2. Загрузите заполненный шаблон с 3 клиентами.
3. Нажмите «Загрузить» / «Отправить».

**Ожидаемо:** переход на экран сверки `/submit/{token}/review/{draft_token}`. Видны:
- партнёр, период, приложение (если одно — выбрано автоматически),
- таблица клиентов (Location ID, оборот, валюта),
- итог: число клиентов, оборот, ставка, сумма к выплате,
- кнопки «Подтвердить» / «Отменить».

**Истории:** P-02, P-09, P-13.

---

### Шаг 4. Подтверждение

1. Нажмите «Подтвердить».
2. Должна открыться страница «Спасибо, отчёт сдан».

**Ожидаемо:** в `/admin/partners/{id}/edit` появился новый отчёт со статусом «Партнёр сдал отчёт».

**Истории:** P-13, P-16.

---

### Шаг 5. Один клиент

1. Откройте персональную ссылку заново (для того же партнёра).
2. Загрузите шаблон с одним клиентом.

**Ожидаемо:** экран сверки открылся. Никакого «отчёт отклонён, потому что один клиент».

**Истории:** P-07.

---

### Шаг 6. Несколько приложений

1. Откройте ссылку партнёра с **несколькими** приложениями.
2. Загрузите файл.

**Ожидаемо:** на экране сверки — селект «Приложение», в нём **только свои** приложения. После выбора — итог пересчитывается.

**Истории:** P-10, P-12.

---

### Шаг 7. Нет приложений

1. Откройте ссылку партнёра **без** приложений.
2. Загрузите файл.

**Ожидаемо:** понятная ошибка «обратитесь к администратору». Никакой черновик не создан.

**Истории:** P-11.

---

### Шаг 8. Битый период

1. Загрузите шаблон с очищенной ячейкой `B3`.

**Ожидаемо:** ошибка «не удалось определить период». Никакого черновика.

**Истории:** P-04.

---

### Шаг 9. Скачивание CSV

1. На экране сверки (`/submit/{token}/review/{draft_token}/`) найдите ссылки «Скачать полный отчёт» и «Скачать расхождения».

**Ожидаемо:** оба CSV скачиваются. В «расхождениях» — только строки, которые отличаются от сверочной базы (если она есть).

**Истории:** — (служебная проверка `/full-report.csv` и `/differences.csv`).

---

### Шаг 10. Переприсылка

1. После шага 4 (подтвердили отчёт) зайдите на `/submit/{token}` ещё раз.
2. Загрузите новый файл за тот же период, **без подтверждения** (просто экран сверки).

**Ожидаемо:**
- Появился новый черновик.
- Ранее подтверждённый отчёт остался актуальным.

**Истории:** P-14.

---

### Шаг 11. Исправленная версия

1. В админке подтвердите исходный отчёт.
2. Через веб загрузите исправленный файл за тот же период.
3. Подтвердите.

**Ожидаемо:** новая версия отчёта, старое подтверждение сброшено.

**Истории:** P-15.

---

## Что записать в протокол

| Поле | Что писать |
|---|---|
| ID сценария | `submit-flow` |
| Дата и время | когда прогоняли |
| Проверил | кто именно |
| Ветка и коммит | `git rev-parse HEAD` |
| Среда | `127.0.0.1:43127`, версия `revshare-web` |
| Браузер | какой использовался |
| Состав | тестовые или реальные партнёры |
| Ограничения | что не удалось проверить и почему |
