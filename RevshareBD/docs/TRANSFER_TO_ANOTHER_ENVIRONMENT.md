# Перенос Revshare в другой контур

Архив `RevshareBD-transfer-2026-10-04.zip` содержит текущую рабочую копию проекта: исходный код, тесты, документацию, BPMN, историю Git в файле `revshare-history.bundle`, базу SQLite и загруженные отчёты.

В архив специально не включены:

* `data/secrets.env`;
* `data/google-service-account.json`;
* токены MCP и Telegram chat ID, сохранённые в SQLite;
* виртуальное окружение Python и кэши.

Это сделано, чтобы архив не содержал ключей доступа. Он всё равно содержит рабочие данные партнёров и загруженные отчёты, поэтому передавать его нужно через защищённое хранилище или защищённый канал.

## Как восстановить проект

1. Распакуйте архив в рабочую папку.
2. Передайте отдельно, через защищённый канал, `data/secrets.env` и `data/google-service-account.json`, если используется Google Таблица. Поместите их в папку `data` рядом с `revshare.db`.
3. Создайте виртуальное окружение Python и установите зависимости из `pyproject.toml`:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -e '.[dev]'
   ```

4. Настройте новые значения `REVSHARE_PUBLIC_URL`, пароль админки, SMTP и токен Telegram в `data/secrets.env` по примеру `secrets.env.example`.
5. На странице настроек повторно подключите Altegio MCP. Архив не переносит его access token и refresh token.
6. Запустите тесты `pytest -q`, затем локальный веб-интерфейс и фоновый процесс по инструкциям из `README.md`.

## Что сохранено в базе

`data/revshare.db` сохраняет карточки партнёров, приложения, персональные ссылки, историю отчётов, результаты сверки, начисления, сохранённые снимки Altegio и настройки, не содержащие секретов. Все оригиналы отчётов находятся в `data/uploads`.

## История разработки

Файл `revshare-history.bundle` содержит Git-историю на дату сборки. Чтобы восстановить её в отдельном каталоге:

```bash
git clone revshare-history.bundle RevshareBD-history
```

Архив уже содержит текущую рабочую копию вместе с незакоммиченными изменениями, поэтому для продолжения работы достаточно распаковать его. Bundle нужен для просмотра и восстановления истории коммитов.
