# BPMN Revshare

Состояние на 04.10.2026. Источник статусов: [аудит проекта](../../PROJECT_STATUS.md).

`revshare-readiness.bpmn` содержит модель BPMN 2.0 с цветами готовности и описаниями всех 32 функций. Модель описывает целевой процесс с текущей степенью реализации; она не предназначена для исполнения движком автоматизации.

В модели шесть диаграмм: общий процесс, сбор отчётов, разбор и валидация, автоматическая сверка, результат и начисления, подготовка к запуску. Последняя описывает отдельный процесс запуска продукта, а не обработку каждого отчёта. Действия пользователя и развилки без номера F служат контекстом процесса и не входят в 32 задачи.

Цвета функций:

* Зелёный: готово в коде, 6 функций. Не является подтверждением работы внешних сервисов в эксплуатации.
* Жёлтый: частично, 19 функций.
* Красный: не реализовано, 6 функций.
* Серый: эксплуатационная готовность не подтверждена, 1 функция.

Идентификаторы F01–F32 соответствуют порядку строк в таблице аудита. Технические пояснения и критерии сохранены в `documentation` каждого элемента BPMN. Цвета хранятся в расширении `bioc`, поддерживаемом редакторами семейства bpmn.io. Редактор без поддержки этого расширения может показать стандартные цвета.

Интерактивное представление в чате позволяет выбирать процесс и нажимать узлы для чтения описания. Изменение выбора не влияет на данные продукта.

Проверено: все 32 функции представлены ровно один раз в детализации; ссылки потоков указывают на существующие узлы; XML читается; шесть экранов и выбор деталей работают в браузере при ширине 800 и 390 пикселей. Полная проверка исполнения BPMN не применима: модель неисполняемая.
